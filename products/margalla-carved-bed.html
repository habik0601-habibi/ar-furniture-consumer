How this page uses RoomSense

This website is plain HTML. It was not built with RoomSense. To add RoomSense, the store pasted two lines:

<script src="https://ar-furniture-liard.vercel.app/widget.js" defer></script>
<div data-roomsense data-store="hearth" data-product="margalla-carved-bed" data-color="#2f4a3a" data-height="440"></div>

The first line goes once in the site's template; the second goes where the product photos would be. RoomSense runs in an isolated frame, so it cannot change this page's design.
